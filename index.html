▶ $ ./what_is_project_shram

Project Shram is an open-source platform for developers to share projects, templates, tech guides, and learning resources. It's a one-stop hub for building, learning, and growing your tech skills.

Think of it as: GitHub + Stack Overflow + Dev Tutorials = Project Shram

▶ $ ./is_it_free

✓ 100% Free & Open Source

No paywalls, no premium tiers, no hidden costs. Everything is free forever. All code is MIT licensed.

▶ $ ./how_do_i_contribute

Contributing is easy! Here's how:

git clone https://github.com/jaswanth-mjy/project-shram.git
cd project-shram
# Add your project/template/guide
git add .
git commit -m "feat: Add awesome project"
git push origin main

Or simply open an issue with suggestions!
