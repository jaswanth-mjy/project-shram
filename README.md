## 🎨 `./design_philosophy`

### Terminal Aesthetic
- **Dark Mode Only**: Pure black (#000) backgrounds
- **Cyan Accents**: Primary color (#00ffff)
- **Green Highlights**: Secondary color (#00ff88)
- **Monospace Fonts**: JetBrains Mono for that terminal feel

### Performance First
- **Zero Dependencies**: Vanilla JavaScript only
- **Optimized Assets**: WebP images, minified code
- **Fast Load**: Sub-second page loads
- **Mobile Optimized**: Works on 2G networks

### User Experience
- **Smooth Animations**: Fade-in effects on scroll
- **Keyboard Navigation**: Ctrl/Cmd+K for quick section jumps
- **Progress Tracking**: Visual scroll progress bar
- **Accessibility**: Focus states, semantic HTML

### Custom Domain Setup

1. Add `CNAME` file with your domain
2. Configure DNS:
   ```
   Type: CNAME
   Name: projectshram
   Value: yourusername.github.io
   ```
3. Enable HTTPS in GitHub Pages settings
